# 🖨️ Low Cost FDM 3D Printer

A custom-built **Fused Deposition Modeling (FDM) 3D printer** developed using embedded systems, mechanical design, and open-source firmware.

This project demonstrates a **low-cost, scalable 3D printing solution** with full hardware integration and system-level design.

---

## 🚀 Features

- Build Volume: 200 × 200 × 170 mm  
- Cartesian Motion System  
- Marlin Firmware Support  
- 12864 LCD Interface  
- Heated Bed with Temperature Control  
- Modular & Upgradeable Design

## 🧰 Parts List – 3D Printer Wiring Diagram

### 🔌 Power System
- 24V SMPS Power Supply  
- Power Input Wires (AC Input)  
- DC Output Wiring (+V, GND)  

### 🧠 Control Board
- BIGTREETECH Control Board  
- Stepper Driver Modules  

### ⚙️ Stepper Motors
- NEMA 17 Stepper Motor – X, Y, Z, Extruder  

### 🔥 Heating Components
- Heated Bed (24V)  
- Hotend (Heater Cartridge + Thermistor)  

### 🌡️ Sensors & Probes
- Inductive Probe  
- BLTouch  
- ADXL345  

### 🔘 Endstops
- X, Y Endstop Switches  

### 🌬️ Cooling
- Hotend Fan  
- Part Cooling Fan  
- Controller Fan  

### 🖥️ Display
- 12864 LCD Display  

### 🔌 Wiring
- Motor, heater, thermistor, fan, power cables
