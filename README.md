# 🖨️ Low Cost 3D Printer

A custom-built **Fused Deposition Modeling (FDM) 3D printer** developed using Arduino Mega, RAMPS 1.4, and Marlin firmware.  
This project focuses on creating a **low-cost, scalable, and maintainable 3D printing solution**.

---

## 🚀 Features

- Build Volume: 200 x 200 x 170 mm
- CoreXYZ / Cartesian Motion System
- Marlin Firmware (v2.1.2.5)
- LCD 12864 Display Interface
- Low-cost and modular design
- Supports PLA printing

---

## 🧰 Hardware Components

- Arduino Mega 2560  
- RAMPS 1.4 Shield  
- A4988 Stepper Drivers  
- NEMA 17 Stepper Motors  
- 12V 30A Power Supply  
- Heated Bed (12V)  
- E3D V6 Hotend  
- GT2 Belt & Pulley System  

---

## 💻 Software Used

- Firmware: Marlin  
- Slicer: Cura / Prusa Slicer  
- Host Software: Pronterface
